Every version, by layer

Click any version to branch from it. Lit versions can be in a stack with your selection; faded ones cannot.

Lit means a complete valid stack exists containing both that version and your selection — not just that two products happen to list each other. Supervisor, VKS and VKr are grouped by version line; vCenter is not, because its patch letter changes what it supports. A grouped node stands for several releases and clicking it selects the newest — hover to see which, and the rest. Where the matrix hedges, so does the picture: dashed means upstream lists the combination compatible without testing it, dotted means it published no result for that pair at all and the connection is inferred from the rest of the stack.
