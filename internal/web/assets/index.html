Every version, by layer

Click any version to branch from it. Lit versions can be in a stack with your selection; faded ones cannot.

Lit means a complete valid stack exists containing both that version and your selection — not just that two products happen to list each other. Supervisor, VKS and VKr are grouped by version line; vCenter is not, because its patch letter changes what it supports. A grouped node stands for several releases and clicking it selects the newest — hover to see which, and the rest. Where the matrix hedges, so does the picture: dashed means upstream lists the combination compatible without testing it, dotted means it published no result for that pair at all and the connection is inferred from the rest of the stack.

The map answers one question at a time, for a person. The same answers come out of a CLI as JSON, and out of an MCP server as typed tools, for everything else.

Wire it into an agent

Nothing to install first. This is the whole setup, in any client that reads an mcpServers object — Claude Desktop, Cursor, Windsurf, Codex, Continue: 

{
  "mcpServers": {
    "vkstack": {
      "command": "npx",
      "args": ["-y", "@warroyo90/vkstack-mcp", "mcp", "--refresh-if-empty"]
    }
  }
}

Claude Code takes it as one line:

claude mcp add vkstack -- npx -y @warroyo90/vkstack-mcp mcp --refresh-if-empty

npx pulls the @warroyo90/vkstack-mcp package, which declares one prebuilt binary per platform as an optional dependency, so a machine downloads only its own. --refresh-if-empty fills the local cache the first time the server starts, which is what makes a machine nobody prepared answer at all — about a minute, once.

Or put the binary on your PATH

curl -fsSL https://raw.githubusercontent.com/warroyo/vkstack/main/install.sh | sh
vkstack refresh

One static binary, no runtime dependencies, checksum-verified against the release's own list. vkstack refresh is not optional: it pulls the matrix into a local cache, and every question after it is answered offline. Nothing else in the tool reaches the network.

What it answers

vkstack stack vcenter 8.0U3k
the whole valid stack from one or more pinned versions — this page, as JSON
vkstack check --vcenter … --esx …
validate a stack you already have; exit 6 means incompatible
vkstack compat supervisor v1.31.11+vmware.8-fips-vsc9.1.0.0
the raw pairwise answer for one release, grouped by product
vkstack describe
the whole agent-facing contract — commands, schemas, exit codes — as data

Add --human to any of them for tables and prose instead of JSON.
