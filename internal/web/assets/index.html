Lit means a complete valid stack exists containing both that version and your selection — not just that two products happen to list each other. Supervisor, VKS and VKr are grouped by version line; vCenter is not, because its patch letter changes what it supports.

The matrix answers one question at a time: is A compatible with B. This is the shape of the whole dependency — which component pins which, how each claim is known, and where there is simply no published answer.
